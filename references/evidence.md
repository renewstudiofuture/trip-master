# 任务状态与证据

信息状态分开记录：

| 状态 | 含义 |
| --- | --- |
| 订单已核 | 从与本次行程相关的有效订单中直接读取的字段 |
| 用户确认 | 用户明确提供，尚未独立读取凭证 |
| 官方当期信息 | 已核对来源和适用日期的公开信息，不等于实时余票 |
| 公开参考 | 平台页面、历史公告、搜索摘要，记录其限制 |
| 规划估算 | 预算或行程缓冲，没有实际报价／实测依据 |
| 待核实 | 缺少影响判断的证据，说明缺什么 |

每条重要数据至少保留：项目、值、状态、来源、核实日、适用日期；需要报价时补查询人数／房间数和日期。字段独立核实，看到订单标题不代表已核早餐、取消或行李。

轻量状态文件建议内容：

1. 用户约束：日期、人数、预算、固定景点、已排除平台、返程条件；未确认假设另列。
2. 已订清单：有效订单、用户确认预订；取消订单只保存必要摘要。
3. 当前行程：每一天的固定事项、候选安排、关键依赖。
4. 证据表：价格、车程、预约来源及日期。
5. 待办：按是否影响成行排序；用户修改时同步删除已过时待办。

金额分别标记已支付、已订未付、报价、预算估算；全程总预算包含已订与未订，但剩余待支付不能把已购门票再计入。旧退票损失若需计算应单列，不与新订单混算。

最终文档只写任务必要的信息。不包含姓名、证件、完整订单号、账户标识和签名详情链接；私密资料不送入公开搜索查询。
