# 免费发布手机行程

用户要求微信内点击跳转或分享时，优先考虑Cloudflare Pages免费静态托管，GitHub Pages作为备选；使用服务提供的免费子域名，不默认购买套餐或域名。先核对当前官方文档及免费限制，不能承诺所有网络或微信环境一定可达。

- 发布须有用户授权；仅上传网页成品，不上传订单截图、证件、私人核实记录、账号配置或带签名URL。
- Cloudflare：可用时遵循cloudflare与wrangler技能，复用既有授权；只有实际缺少权限才请求所需读取与Pages发布权限。邮箱未验证时明确提示用户验证，不要求重复登录。先列项目，复用已存在项目；没有才创建；用实际CLI帮助和错误判断新旧命令行为，不盲目重试或默认强制参数。
- 静态目录只含index.html和必要公开资源，无须服务端、数据库或收费功能。得到实际部署URL后检查HTTP状态和内容是否对应本次文件；再请用户验证手机访问，记录验证范围。
- GitHub Pages：使用用户授权的仓库；免费个人方案通常要求公开仓库，发布前核实当前规则。只推送网页发布目录；仓库公开不等于Pages已启用，必须确认实际站点URL。
- 域名被拦截时，区分部署状态、公开权限与实际访问；不把发布成功等同于用户可达。不要靠换短链接掩盖同一被拦截域名。
- 保存公开URL及项目标识到该旅行工作目录，后续更新同一入口；凭据交给官方认证机制，不能写入技能或Git仓库。
