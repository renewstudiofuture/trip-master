# Markdown 与 PDF 导出

手机／微信交互需求优先按[手机网页规则](mobile-web.md)生成HTML，PDF不是交互兼容性保证。

最终PDF默认采用[随身行程设计](pdf-design.md)：日期导航、每日路线与独立交通／住宿卡片，使用`build_cards_pdf.py`。Markdown保留完整来源与核实记录。下面的长文导出仅用于用户明确需要传统文档时，不再作为默认版式。

完整攻略默认两种格式，简单修改按用户需求。优先使用当前环境可用的PDF技能及其规定；本包脚本提供不依赖浏览器或Edge的ReportLab导出方式。

```bash
python scripts/build_pdf.py outputs/攻略.md outputs/攻略.pdf --title "旅行攻略"
```

运行前检测Python的reportlab依赖与中文字体，优先使用平台提供的运行时。缺少依赖时使用获准的安装机制或明确说明缺失，不无限尝试浏览器打印。可通过 `--font /path/font.ttf` 指定可嵌入中文TrueType字体；TTC通过 `--font-index` 选择。不要用不支持中文的字体假装成功。

支持：标题、正文、简单列表、Markdown表格、加粗、普通HTTP(S)链接，以及 `<!-- PAGEBREAK -->` 手动分页。复杂嵌套表格、内嵌HTML、图片、代码块等需先简化或使用专业文档工具；不得期待此轻量脚本完整支持所有Markdown。

按内容组织，不强制一章一页；可在需要时用分页标记。脚本会让短表格整体放置，长表格分页时重复表头；单行过高或复杂表格需编辑源文件，不能缩小到不可读字号。

生成后用可用的 `pdftoppm` 渲染所有页并查看，核对中文缺字、链接、表格、标题和尾页；文本提取核对金额与日期，不能只检查文件大小／页数。发现问题修复后复查受影响页面。

输出文件放用户工作目录的outputs中，临时渲染与测试文件单独存放。交付时提供Markdown与PDF可访问引用；若有当期PDF技能的特殊引用格式，遵循其规则。不自动上传公开站点。
